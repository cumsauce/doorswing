# Door Swing

Client-side Fabric mod that animates vanilla door opening/closing.

- Minecraft 26.3, Fabric Loader 0.19.5, Java 25
- Built with `net.fabricmc.fabric-loom` (unobfuscated 26.x style)

Build:

```sh
JAVA_HOME=/opt/homebrew/opt/openjdk@25 ./gradlew build
```

Releases are built by GitHub Actions on `v*` tags.
